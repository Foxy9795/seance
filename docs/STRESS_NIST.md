The programs are the NIST CCVS85 suite, split by its own EXEC85 program the way GnuCOBOL's test run splits it (`build/corpora/nist`, not part of this repository). Each program is compiled with GnuCOBOL 3.1.2 and translated by Séance; it counts as matched only when the Python writes every byte the COBOL wrote: the report file, every other file and the console.
