# Translator stress test

Generated by `python scripts/stress_translate.py`. The programs come from GnuCOBOL's own test suite (gnucobol-3.1.2), fetched at run time and not stored in this repository. The compiled COBOL is the judge; the suite's expected output is not used.

History of this measurement. First run: 113 of 466 usable programs matched (24%). Release 1.0.0: 141 of 466 (30%). Release 1.1.0 adds compiler directives, REPLACE, named constants, DECIMAL-POINT IS COMMA, several programs in one file, DELETE FILE and LENGTH OF: 165 of 464 (36%). Each fix has a test in tests/test_translator_stress.py that compares with GnuCOBOL.

How to read this. The suite exists to test GnuCOBOL itself, so it is full of extensions, compiler options and corner cases that ordinary business programs never use. A program counts as matched only when every byte the COBOL wrote is reproduced by the Python. A program that does not match is not silently accepted: the check reports it, and statements the translator cannot translate raise an error that names the COBOL line. The tables below are where to look next.
