    Move COBOL To Python. Prove Nothing Changed.

    Séance compiles your COBOL with GnuCOBOL, writes the Python for you, then runs both programs on the same input, record by record and byte by byte. You get the Python and a report that shows it behaves the same, or exactly where it does not.

    1

    Add Your Program

    Drop in a .cbl file and its copybooks. Séance compiles it and runs it on hundreds of generated inputs to record what it really does.

    2

    Get The Python

    A rule-based translator writes Python that keeps COBOL's data exactly: packed decimal, rounding, truncation, tables. Every line points back to its COBOL line.

    3

    Prove It Matches

    The check replays every recorded run and fresh random ones. Any difference is shrunk to the smallest input that shows it.

        Run The Check

        Replays every saved run of the COBOL through the Python and compares every output byte, then runs both programs on fresh random input. Takes a few seconds.

        Test Strength

        Breaks the Python on purpose, one small bug at a time (a > turned into >=, a ROUNDED dropped, a constant changed) and checks that the saved runs catch each one. A bug that slips through points at code no test reaches.

        Test Data

        The saved runs used by the check. Add your own production-like data: the COBOL runs on it first, and its output becomes the expected answer.

        Try Your Input

        Type or paste input, then run the COBOL and the Python side by side. Lines that differ are highlighted.
