1. Record

Your COBOL is compiled with GnuCOBOL and run on generated input: edge values, random records, the values its own IF tests use. Its output is the expected answer.

2. Translate

A rule-based translator writes Python that keeps COBOL's data byte for byte: packed decimal, rounding, truncation, tables, indexed files, CALLs. Each line names its COBOL line.

3. Check

Every saved run is replayed through the Python and fresh random runs go through both. Differences shrink to the smallest input that shows them; unreached COBOL lines are listed.
