Séance

What Séance does

It proves that the Python written for your COBOL gives the same answers as the COBOL. The original program is compiled and run by GnuCOBOL; its output is the answer key. Every byte the Python writes is compared with it.

How to use it

  1. Add your COBOL: drop the files anywhere on the page, or press Add Program. Copybooks and called programs go in the same drop.
  2. Séance runs the original on edge values and random records, and writes the Python.
  3. Press Check. Both run on every saved input and on fresh random data.
  4. Put your own data in the Test Data tab (any size; drop several files at once).

The tabs of a program

Overview
what the program is, and the result of its last check
Code
the COBOL and the Python side by side; click a Python line to see its COBOL line
Analysis
flow of the paragraphs, business rules, data dictionary, where each field comes from
Check
runs the proof, shows coverage, and plants small bugs to see if the tests notice
Try Input
runs both sides on one input you type
Test Data
your own input files, the saved test sets, and output from your own mainframe

The words

Spirit matched: every byte is the same. Spirit restless: they differ, and the Python is what to fix. Coverage: how many COBOL statements the saved runs reach.

A file too big for the page (several GB)? Run python -m seance bigcheck PROGRAM FILE. Nothing you add leaves this machine.
